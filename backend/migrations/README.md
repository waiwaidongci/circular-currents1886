# Schema v2

v1由SQLAlchemy metadata建立users、audits、direction_surveys、moorings、bearing_readings、direction_runs、observation_notes。调查/浮标/采样code唯一，角度为MySQL DOUBLE，运行和说明通过外键关联。

v2新增joint_runs（多浮标联合研究，含JSON列mooring_ids与逐次各对统计量null_statistics）；observation_notes增加可空joint_run_id，run_id改为可空，并以CHECK约束保证恰好关联一类研究。双组研究相关表结构不变。

本合成数据项目没有生产增量迁移；schema变更应另建正式迁移，一次性重置可down -v后重建。v1存量库需重置后重建，或手工ALTER补列。
